# Portfolio-Website

This is a personal portfolio website showcasing my skills, education, projects, and experience.
It's built with HTML, CSS, and JavaScript, following a modular structure for better maintainability.

## Features

- Dynamic content loading for sections (Home, About, Skills, Education, Work, Experience, Contact).
- Responsive design.
- Interactive elements (particles.js, typed.js, vanilla-tilt.js).
- Contact form with EmailJS integration.
- Separate pages for full projects list and full experience timeline with filtering capabilities for projects.
- Developer mode disabled for production (F12, Ctrl+Shift+I/C/J, Ctrl+U).

## Technologies Used

- HTML5
- CSS3
- JavaScript (jQuery, Typed.js, Particles.js, Vanilla-Tilt.js, EmailJS, Isotope)
- Font Awesome for icons

## Project Structure

The project is structured to separate concerns, with each major section having its own HTML and JavaScript files within the `sections/` directory.
